# ЕдуЕм design assets

Минимальный набор ассетов из Figma для production-лендинга.

Структура:

- hero/ - главный экран и доставка к вагону
- app/ - блок мобильного приложения, QR и ссылки магазинов
- ordering/ - варианты заказа через сайт и приложение
- partners/ - логотипы партнеров
- brand/ - логотипы и фирменные элементы
- banners/ - дополнительные баннеры
- icons/ - небольшие SVG иконки

Принцип сборки:

- изображения используются как отдельные assets;
- верстка и текст собираются React-компонентами;
- не используем большие экспортированные SVG всей страницы из Figma;
- тяжелые изображения переводим в WebP/AVIF.
