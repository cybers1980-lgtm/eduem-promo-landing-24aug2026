# ЕдуЕм design assets

Минимальный набор ассетов из Figma для сборки лендинга.

Структура:

- hero/ - главный экран
- app/ - блок мобильного приложения
- ordering/ - варианты заказа
- partners/ - логотипы партнеров
- icons/ - небольшие SVG иконки

Принцип:
- изображения используются как отдельные assets;
- верстка и текст собираются React-компонентами;
- не используем большие экспортированные SVG всей страницы.
