# Asset optimization plan

## Current assets

Large Figma exports are kept as source files.

## Production versions

Create optimized assets:

- hero/hero-delivery.webp
- app/app-screen.webp
- ordering/ordering-options.svg
- banners/food-banner.webp

## Rules

- Do not use full-page Figma exports in production.
- Keep text and buttons as React components.
- Use SVG for logos and icons.
- Use WebP for large photos.
